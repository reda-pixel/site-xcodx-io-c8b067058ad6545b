🚀 Core Architecture

XCODX runs 100% in-browser without external server reliance for client apps. React JSX is parsed on the fly using Babel Standalone, while styles are composed with modern CSS and Tailwind.

📦 Offline Data Persistence

Every file modification and custom script is saved directly to your browser's persistent localStorage and IndexedDB storage. You can freely refresh or reopen without loss of progress.
